Privacy Policy

Effective 17 October 2026

Who this covers

This policy covers Flag League Uploader, a private tool used only by the owner of the YouTube channel Flag League (@FlagLeaguee) to publish videos to that channel. No one else signs in to it.

Google user data the app accesses

With the channel owner's consent (Google OAuth), the app uses these YouTube scopes:

  • youtube.upload — upload the channel's own videos;
  • youtube — set titles, descriptions, playlists and thumbnails of those videos, and read the channel's ID and recent uploads to confirm it is publishing to the right channel and never twice;
  • yt-analytics.readonly — read view counts and watch-time figures of the channel's own videos.

Separately, with an API key and no sign-in, the app reads the text of public comments on the channel's own videos once a week to count which countries viewers ask for.

How the data is used and stored

  • The OAuth refresh token is stored encrypted on the channel owner's own server and is used only to act on the owner's channel.
  • Analytics are stored as aggregate numbers per video and used only to plan future videos.
  • Comment text is not stored. Only the country counted, the number of votes and a few comment IDs as samples are kept.
  • No data is sold, shared with third parties, used for advertising, or combined with other data.

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The app uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Retention and deletion

Access can be revoked at any time at myaccount.google.com/permissions or via Google security settings. After revocation the stored token stops working; it and any stored analytics are deleted within 30 days of a request.
